## 차곡차곡

드라이브하는 동안 아이와 가족이 나눈 말이 가사가 되고, 차가 달리는 속도가 노래의 비트가 돼요. 완성된 노래는 고른 친구 캐릭터가 춤추는 화면에서 듣고, 그 차의 보관함에만 저장해요.

- **속도가 비트로**: 정차·골목·시내·고속 구간마다 2·4·8·16비트
- **목소리가 가사로**: 녹음에서 들린 말로 가사를 만들고, 가족마다 고른 악기를 붙여요
- **차에만 저장**: 서버는 녹음과 완성곡을 오래 두지 않아요
